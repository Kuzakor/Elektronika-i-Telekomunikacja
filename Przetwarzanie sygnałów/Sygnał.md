# Definicja
- Sygnały dzielimy według następujących kategorii
	- Wiedza/przewidywalnosc
		- Sygnał determistyczny - wiemy wszystko
		- Sygnał sochastyczny - wiemy mało
	- Rodzaj [[Dziedzina|dziedziny]]
		- Sygnał ciągły
		- Sygnał dyskretny
	- Przyczynę
		- Sygnał przyczynowy - zaczyna się od 0
		- Sygnał nieprzyczynowy - nie zaczyna się od 0
	- [[Okresowość funkcji|Okresowość]]
		- Okresowe
		- Prawie okresowe
		- Poza okresowe
