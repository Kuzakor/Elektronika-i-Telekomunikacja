#informatyka #systemy_sieci
# Definicja
- Jest to przejście z sieci typu jedna sieć - jedna usługa do jednej sieci *warstwowanej*
### Warstwy
- Usług/aplikacji
- Sterowania
- Transportu
- Dostępu
### Interfejsy połączeń z użytkownikami i otoczeniem
- *UNI* - interfejs użytkownik - sieć
- *ANI* - interfejs węzła aplikacji
- *SNI* - interfejs węzła usługowego
- *NNI* - interfejs międzywęzłowy

### [[Model warstwowy ISO OSI RM]]
- Model warstwowy dla NGN wygląda następująco (z góry na dół)
	1. Network Service Layer
	2. Control Layer
	3. Media Layer 
	4. Acces and transport Layer
	5. Uzytkownicy różnego rodzaju
