# Definicja
- Jest to [[Równania rózniczkowe|równanie różniczkowe]] w którym występuje maksymalnie [[Pochodna|pochodna]] [[Pochodne wyższego rzędu|pierwszego rzędu]].
$$
\frac{dy}{dx} +p(x) y =q(x)
$$
- Dla q(x) = 0 jest to równanie *równorodne*, dla q(x) nie będącego 0 jest to *równanie niejedrodone*
