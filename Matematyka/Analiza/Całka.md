#matematyka #analiza 
# Definicja
- Całka opisuje pole pod wykresem danej [[Funkcja|funkcji]]. Jest to suma nieskończenie małych prostokątów które nam to pole określają.
- Jednocześnie jest to odwrotność [[Pochodna|pochodnej]]
### Rysunek - przykład
[[Całka.excalidraw]]
# Wzór
$$\int_{}^{}f(x)dx = F(x)$$
$$\frac{d}{dx}F(x) = f(x)$$
$$\int_{a}^{b}f(x)dx = F(b) - F(a)$$

# Przykład
$$\int_{}^{}(-x^2+8x)dx = -\frac{1}{3}x^{3} + 4x^2 +C$$
$$\int_{0}^{8}(x^2-8x)dx = \left(-\frac{1}{3}8^{3} + 4* 8^2 + C\right) - \left(-\frac{1}{3}0^3 +4*0^2 + C\right) = -\frac{512}{3}+256 = 85\frac{1}{3}$$
# Opis
- Z całego pola nad wykresem wydzielamy ten kawałek który nas interesuje a -> b.
- C to dowolna stała która znika przy obliczaniu pochodnej. Musimy ją dopisać gdyż nie ma możliwości znania ile ona wynosi.
