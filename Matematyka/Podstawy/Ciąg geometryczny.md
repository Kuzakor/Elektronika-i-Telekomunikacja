# Definicja
Jest to [[Ciąg|ciąg]] w którym poszczególne wartości są iloczynem o jakaś konkretną stałą (np. 3)
$$3,9,27,81,...$$
# Wzór
$$a_n = qa_{n-1}$$
$$a_n = q^{n-1}a_1$$
$$a_1a_3=a_2^2$$
$$\Sigma_n = \begin{cases} na_1, \space q=1\\ \frac{a_1(1-q^n)}{1-q}, \space q\neq1\end{cases}$$
$$\Sigma_{\infty} = \frac{a_1}{1-q}, \space|q| < 1$$
