# Definicja
- Jest to bardzo prosta [[Funkcja|funkcja]] przyjmująca 1 dla wartośći dodatnich, 0 dla 0 oraz -1 dla wartości ujemnych.
- Jest to [[Funkcja]] [[Parzystość funkcji|nieparzysta]]
# Wzór
$$sgn(x) = \begin{cases} 1; \space  x<0 \\ 0; \space x= 0 \\ -1; \space x <0\end{cases}$$
