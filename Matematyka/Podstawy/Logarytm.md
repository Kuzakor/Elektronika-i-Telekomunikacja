# Wzór
$$log_{a}b = c \Rightarrow a^{c}= b$$
### WAŻNE: Specjalnym logarytmem jest tak zwany logarytm naturalny, jest to logarytm o podstawie równej [[Liczba eulera (e)|liczbie eulera]]. Jego wynik to ile razy trzeba podnieść e by otrzymać daną liczbę
$$log_{e}x = ln(x)$$
