#matematyka #algebra_liniowa
# Definicja
- Jeżeli 8 fundamentalnych zasad jest spełnionych to rzeczy zawarte w algebrze liniowej można sotosować w innych polach matematyki takich jak np. [[Funkcje a algebra liniowa|analiza]].
# 8 zasad:
1. $$\vec{u} +({\vec{v} + \vec{w}}) = (\vec{u} +{\vec{v}) + \vec{w}}$$
2. $$\vec{v} + \vec{w} = \vec{w} + \vec{v}$$
3. Istnieje wektor 0 dla każdego wektora taki że $$0+\vec{v} = \vec{v}$$
4. Dla każdego wektora istnieje wektor ujemny taki że $$\vec{v} + (-\vec{v}) = 0$$
5. $$a(b\vec{v}) = (ab)\vec{v}$$
6. $$1\vec{v} = \vec{v}$$
7. $$a(\vec{v} + \vec{w}) = a\vec{v} + a\vec{w}$$
8. $$(a+b)\vec{v} = a\vec{v} + b\vec{v}$$
